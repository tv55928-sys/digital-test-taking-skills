# Ready for EQAO Math

An interactive learning module that helps English language learners in Ontario's Grade 9 de-streamed math course (MTH1W) build digital test-taking skills for the EQAO Grade 9 Assessment of Mathematics. The math examples come from the Characteristics of Relations unit (C4.1 and C4.4).

## What's inside

Ten stations, in order:

1. **Welcome**: learning goals and a feelings check-in
2. **Set up your desk**: an allowed/not-allowed sort, a desk layout for right- or left-handed writers, and a pre-test checklist
3. **Paper first**: the Read → Write → Solve → Check → Click routine, with a whiteboard worked example
4. **Anchor charts**: four classroom charts and a "which chart helps?" activity
5. **Desmos**: six Desmos moves, a slope/y-intercept slider lab, and a table checker for linear vs. non-linear relations
6. **Break down the question**: highlighting key words, plus an 18-term word wall with space for students' first language
7. **The test screen**: a guided tour of a practice test screen (read aloud, zoom, line reader, highlighter, calculator, documents, flag, review)
8. **Calm and confident**: box breathing, self-talk cards, and stress-to-strategy cards
9. **Practice test**: Stage 1 (10 math questions, 4 of them EQAO released questions) and Stage 2 (12 test-skills questions), with explanations
10. **Tips for success**: before/during/stuck/submit tips, a test-day plan, and a check-out

There is also a **Teacher notes** page with curriculum connections (C4.1, C4.4, AA1), a social-emotional learning (SEL) skills map, a suggested lesson flow, and sources.

## Publish with GitHub Pages

1. Create a new repository and upload `index.html` and `README.md`.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. After a minute or two, the site is live at `https://<your-username>.github.io/<repository-name>/`.

## Notes

- It's a single self-contained file with no build step. The only external resource is Google Fonts (Lexend and Kalam).
- Student notes, check-ins and progress are saved only in each student's browser (`localStorage`). Nothing is sent to a server.
- The Listen buttons use the browser's built-in text-to-speech, which varies by device.
- The practice test screen only approximates the EQAO platform. It is not the real platform. Students should also try EQAO's official sample test at https://www.eqao.com/the-assessments/grade-9-math/.
